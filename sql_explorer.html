SQL Explorer

Run real SQL against the live scanner database — in your browser, read-only, nothing leaves your tab.

Loading sql.js and data/scanner.db…
Read-only: only SELECT/WITH is allowed. Results capped at 500 rows. A company name in the results links to its full digest brief when company_number is also selected.

This loads data/scanner.db — the same SQLite database the scanner's own pipeline writes to on every run — directly into your browser via sql.js (SQLite compiled to WebAssembly). There is no server involved: the query engine runs entirely client-side, on an in-memory copy of the file your browser just downloaded. Nothing you type here is sent anywhere, and nothing you run can change the real data.
