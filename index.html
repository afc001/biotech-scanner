UK Biotech Deal-Flow Scanner

Automated screening briefs on newly incorporated UK biotech companies, generated from public filings.

This project generates one-page investment screening briefs on early-stage UK biotech companies, drawn from Companies House new-incorporation data (SIC 72110/72190), then cross-checked director-by-director against ORCID (academic publication record), UKRI Gateway to Research (public grant history), and Companies House's own officer-appointment records for a repeat-founder-in-sector signal — all common-name-safe or structurally verified, never guessing at an ambiguous match. Each brief is produced from these sources alone: where there's no supporting data, the field reads “Not observable at this stage” rather than inventing facts.

Generation (structured JSON) is kept separate from presentation (this rendered digest), so the archive can be re-rendered at any time without re-running the model. The pipeline is designed to run unattended on a daily schedule.
